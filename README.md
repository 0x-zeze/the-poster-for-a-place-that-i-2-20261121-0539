A vintage travel poster for **AERIDOR — the isles above the cloud sea**: floating islands at sunset, one great lighthouse on the central isle, a huge low sun, and a sea of clouds below — where the sunset never ends. Every pixel is drawn by the program itself (Python standard library only, with its own PNG encoder and a hand-built 5x7 bitmap font); no image is downloaded or embedded.
## Run it
```sh
python3 main.py
```
